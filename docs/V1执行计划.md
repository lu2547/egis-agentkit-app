# AgentKit V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for owned sequential work. Independent frontend, Nacos, and message-bus domains may use superpowers:dispatching-parallel-agents with exclusive file ownership. Steps use checkbox syntax.

**Goal:** A runnable enterprise WorkBuddy implementation with native AgentScope execution, real PG/Nacos data, versioned packages, three-column Vue UI and visible artifacts.

**Architecture:** Framework holds domain services and native adapters; App composes native create_app and thin controllers. No upstream service edits, repositories, duplicate loops, or fake production data. Nacos holds configuration and Skill/MCP source contents; PG holds enterprise facts and native records.

**Tech Stack:** Python 3.11+, AgentScope 2.0.10/2.0.11 compatible APIs, PostgreSQL 17/SQLAlchemy async, Nacos 3.3, Kafka 3.8, Vue 3/TypeScript/TDesign/Vite.

**Spec:** `V1实施规划.md`, framework `数据结构.md`, `表设计草案.md`, `运行流程.md`, and user corrections recorded below.

## Global Constraints

- Do not modify `harness/agentscope` or copy native ChatService/AgentLoop/SSE.
- No runtime automatic grants; system assets default denied, private own resources allowed by configured rule, sharing only requires admin review.
- Only user/admin. Team→Agent→Skill/Tool/MCP USE inheritance retains independent origins. No EDIT grants.
- Personal standalone/non-invitable; expert standalone/member, never leader; orchestrator only within static Team. Dynamic team tools disabled.
- New package/version hot-load without restarting App. Namespaced imports, immutable version selection, staging/atomic registry.
- Skill flag `is_skill_market_visible`; classification `xxx_type`, flags `is_xxx`; agent_name/agent_display_name/team_name/team_display_name.
- UI lives in egis-agentkit-frontend. Three columns: left navigation/tasks, center chat/resource pages, right Workspace/artifact previews. WorkBuddy expert screenshots govern catalog/modal/forms; agentscope-demo governs thinking/tool/event semantics.
- Nacos Skill Hub and MCP Hub each get a real seeded runnable example. No Redis additions. Kafka consumer-group wakeup replaces cross-node broadcast competition; other state/locks may use PG.
- Configuration only Nacos, minimum bootstrap secrets/addresses from environment. No credentials in client bundles or logs.
- Tests precede new behavior; run meaningful domain/HTTP/stream/path/concurrency/hotload tests and real PG/Nacos/Kafka integration.

## Review Focus

1. An own private edit must not change a previously approved shared execution or inherited permission path.
2. Two concurrent saves/approvals/first-logins must not overwrite data, duplicate personal agents, or create duplicate grants.
3. Agent cancellation/confirmation/reconnect must preserve reply identity and avoid duplicated stream deltas.
4. File preview/download must reject traversal, cross-user paths and symlinks outside the allowed root; artifact HTML must be isolated.
5. Kafka rebalance/crash after claim must not be described as exactly-once execution; manual offset and lock boundaries must be tested explicitly.

## Shared HTTP contract (all paths under frontend /api proxy, backend no /api)

- Bearer authentication. GET `/manager/me` → User including role_type; 401 opens login. POST `/auth/login` body `{user_id,password}` is explicit demo-mode login only. Production JWT uses configured verifier.
- GET `/manager/agents`, `/manager/teams` → `{items: DefinitionView[]}`. Definition fields are models.py plus `resource_view_type`, `is_usable`, `is_editable`, `is_deletable`, `share_status_type`; payload contains description/category/tags/avatar/system_prompt/starter_prompts/model_key/bindings/implementation; team payload orchestrator/members are `{definition_id,resource_view_type}`. Lists exclude orchestrators and personal where appropriate; GET `/manager/assistant` returns personal.
- POST `/manager/agents` body `{agent_name,agent_display_name,payload}`; PUT `/manager/agents/{id}` adds `config_version`; same Team shape with team_name/team_display_name and embedded `orchestrator_config:{agent_name,agent_display_name,payload}`, `members:DefinitionRef[]`. API handles creation atomically. DELETE returns 204.
- GET `/manager/tasks` → `{items:[{session_id,agent_id,name,definition_id,definition_display_name,updated_at}]}`; POST body `{definition_id,resource_view_type,name?,model_key?}` → same item. GET `/manager/tasks/{sid}` → item. Native `/chat/`, `/sessions/{sid}/stream?agent_id=...`, `/messages`, `/interrupt` continue native shapes from demo.
- GET `/manager/models` → `{items:[{key,display_name}],default_key}` (no secrets).
- GET `/manager/skills`, `/manager/connectors` → `{items:[{resource_id,resource_version,owner_type,owner_id,display_name,description,is_usable,is_editable,is_installed,is_enabled,is_skill_market_visible?,payload}]}`. Detail GET `/{id}?version=...`; POST source metadata/body handled by Services and Nacos adapter; POST `/{id}/install`, PATCH `/{id}/installation` body `{is_enabled}`. Skill upload multipart file; edits publish a new version. Native installation remains reusable behind policy.
- GET `/manager/tasks/{sid}/files?area=work|artifacts&path=...` → `{items:[{name,path,is_directory,size,modified_at}],area,path}`. GET `/manager/tasks/{sid}/file?area=...&path=...` returns authorized bytes with media type; text and Markdown preview, image/PDF/blob or download. POST `/.../deliver` body `{path}` commits a work file into artifacts safely. Frontend exposes artifact cards and right preview.
- GET/PUT `/manager/preferences` → `{agent_md,soul_md,user_md}`; memory is native ReMe, no editable memory.md.
- POST `/manager/share-requests` `{resource_type,resource_id,resource_version?}`（Skill/MCP 必须指定版本）; GET same → `{items:Review[]}`. Admin `/manager/admin/users`, `/groups`, `/grants`, `/share-reviews`, `/packages`; decisions POST `/share-reviews/{id}/decision` `{is_approved,reason}`. Admin tabs only visible for admin; server enforces it.
- Unified domain errors `{detail:string}` with meaningful HTTP status. No fabricated success, failures and empty states visible.

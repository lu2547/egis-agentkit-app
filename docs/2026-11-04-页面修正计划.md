> 执行按 superpowers:executing-plans；独立后端、输入/权限和右侧面板任务按 dispatching-parallel-agents 并行，文件所有权不重叠。

**Goal:** 按用户最新截图修正工作台，历史文件持久可找，权限操作独立显示。

**Architecture:** 复用当前 Vue3/TDesign 与 AgentScope service；新增薄管理接口读取用户 work/artifacts/uploads 与管理自己的 Session，不修改原生源码。思考区域的结构和展开行为本轮保留。

**Spec:** 本轮用户五张截图及补充：灰色选中态、克制蓝色交互、不使用绿色/双重边框；平台名养老险GPT；使用原 Logo。

## 视觉与交互

- 颜色：白 #ffffff、页面浅灰 #f7f7f8、选中灰 #eceef0、正文 #202226、次要 #777d86、交互蓝 #2563eb。蓝色只用于按钮/链接/键盘焦点，不做整圈高亮卡片。
- 字体沿用系统中文字体，正文 14px，导航 14px，主标题 24px；边框 1px 浅灰，选中态不叠加外框。
- 输入框为单层圆角容器：上方自动高度文本，下方左侧加号菜单（文件/专家/技能/连接器），右侧模型与发送；资源选择有检索，真实启用状态，不做假的模式切换。
- 左侧“最近任务”改“最近对话”，内容基于用户问题生成标题，可删除。删除对话不删除用户文件。
- 专家页：个人助理、专家、专家团三个入口。个人助理只维护 agent.md（工作范围）、soul.md（决策风格）、user.md（业务背景）。侧栏移除个人助理设置。
- 右侧四个独立面板：计划、工作空间、产物、预览，通过 tabs 切换，支持从文件直达预览。工作空间跨会话显示 work/artifacts/uploads；产物为当前会话交付物；预览保持选中文件，不被流事件刷新清空。计划只读原生真实状态，无计划时明确空态。

## 约定接口

- GET /manager/workspace/files?path=：返回当前用户虚拟根下 work/artifacts/uploads 的安全目录列表，文件 path 为相对用户根的完整路径。
- GET /manager/workspace/file?path=：仅允许上面三个区域的所有者读取，返回原文件字节；现有任务文件接口保持兼容。
- POST /manager/workspace/files（multipart file, path 可选）：保存到 uploads，返回 WorkspaceFile。
- DELETE /manager/tasks/{sid}：仅删除/隐藏本人的对话，运行中明确冲突或安全停止；保留 work/artifacts/uploads。Team 必须处理成员关联，不能留下后台执行。
- 对话命名优先复用原生自动命名；用户显式 name 保持不变，未命名时显示用户首问摘要，不能只显示“个人助理/报告专家”。

## Review Focus

1. 不同用户的文件、会话与上传互相隔离，路径穿越/软链接仍拒绝。
2. 当前 Session 切换不能抹掉历史文件或覆盖选中预览，异步旧请求不能回写新会话。
3. 权限卡始终位于思考折叠区外，保留原 reply ID 与原生确认事件。
4. 删除正在执行的 Team 不得遗留成员运行；删除对话保留用户工作与交付文件。
5. 未知或不可预览的格式提供可用下载，不声称浏览器能原生显示所有二进制格式。

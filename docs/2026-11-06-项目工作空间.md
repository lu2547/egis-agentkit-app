# 项目与共享工作空间实施记录

本次变更取代之前“每个 Session 独立工作目录、删除对话时清理文件”的约定。

- 左侧项目支持新增、展开/折叠、重命名、删除，项目下有多个对话。
- 点击项目直接扫描并显示工作空间；还没有对话也可上传文件。
- 根目录保存上传资料，`.work` 保存过程文件，`artifacts` 是产物目录。
- 项目内对话共享文件、产物、变更与预览；删除对话只删对话数据。
- 删除项目清理其全部会话、事件和文件；运行中拒绝删除。历史文件迁移保留同名不同内容，支持失败重试。
- 保留新 `framework/service` 结构。App controllers 通过 `AgentKitServices` 的具名领域服务调用能力；文件用例归 `WorkspaceService`，HTTP 层负责协议转换。

完整目录、表、接口、并发与迁移规则见 [Project 文件生命周期](../../egis-agentkit-framework/docs/session-files.md)。验证结果在完成真实环境联调后记录于本页。

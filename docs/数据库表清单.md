# PostgreSQL 初始化表清单

首次部署由部署流程或 DBA 执行 [PG 初始化脚本](../../egis-agentkit-framework/scripts/init/pg.sql)建表。AgentScope 表沿用原生模型，Session 增加可索引的项目归属，AgentKit 使用业务专表，cluster 消息总线使用 PostgreSQL 表。

| 来源 | 表 | 用途 |
| --- | --- | --- |
| AgentScope | `agents`、`sessions`、`messages`、`teams` | 原生运行记录、消息历史和团队协作 |
| AgentScope | `credentials` | 原生模型配置引用的凭据 |
| AgentScope | `schedules` | 原生计划记录；扩展项目关联、下一次执行时间及软删除字段，承载受管定时任务 |
| AgentKit | `ak_agent_definition_summary`、`ak_agent_definition_detail`、`ak_team_definition_summary`、`ak_team_definition_detail` | Agent 和 Team 的身份、状态及不可变配置版本 |
| AgentKit | `ak_agent_personal_resources` | 个人的资源选用和启停状态 |
| AgentKit | `ak_agent_invite_candidates` | 个人助理可自动邀请的候选专家选择 |
| AgentKit | `ak_schedule_runs` | 定时任务触发、执行快照、会话、结果及归档记录 |
| AgentKit | `ak_users`、`ak_groups`、`ak_virtual_users` | 真实账号、组织组、外部系统上传身份 |
| AgentKit | `ak_resource_permission`、`ak_approve` | 资源使用授权及共享申请 |
| AgentKit | `ak_skill_summary`、`ak_skill_detail`、`ak_skill_imports` | 技能身份和双版本指针、版本明细、导入任务及上架审批 |
| AgentKit | `ak_resource_assets`、`ak_mcp_credentials` | 连接器、工具目录与连接器凭据 |
| AgentKit | `ak_projects`、`ak_project_file_changes`、`ak_project_file_fingerprints`、`ak_project_reply_artifacts` | 项目、文件变更和扫描基线、回复产物 |
| AgentKit | `ak_agent_remote_runs` | 第三方专家请求去重、回包验签、结果恢复及团队回报状态 |
| AgentKit | `ak_feedback` | 回复反馈及相关会话、模型和回复快照 |
| cluster 消息总线 | `ak_bus_keys`、`ak_bus_entries`、`ak_bus_registry`、`ak_bus_leases`、`ak_bus_broadcast_payloads` | 序号与过期、队列和日志、注册状态、租约及广播载荷 |

AgentScope 原生 6 张、AgentKit 23 张，业务运行表共 29 张。企业 cluster 的 PG 初始化脚本另建 5 张消息总线表，共 34 张。PostGIS 的 `spatial_ref_sys` 属于数据库扩展。虚拟用户上传接口见 [Skill 接入指南](Skill接入指南.md)。

本地开发使用 `127.0.0.1:5433/agentscope`，默认 schema 为 `public`。应用及管理命令使用 Nacos 的 `agentkit.client.postgres.connection` 定位数据库并按 `mode` 读取固定密码或向 CyberArk CCP 取密。

## 数据库发布

首次初始化脚本只用于空 schema，同名表已存在时会报错并回滚。后续数据库结构变更、数据修订及清理统一通过部署流程执行经审核的 SQL 脚本。

应用 CLI 仅提供服务启动和指定用户的管理员授权，不提供数据库初始化、升级、清理、索引优化、技能重置或示例资源导入命令。

# PostgreSQL 初始化表清单

`init-db` 按工作台实际依赖建表。AgentScope 表沿用原生模型，Session 增加可索引的项目归属，AgentKit 表由框架创建，消息总线仅在 cluster 模式初始化 PostgreSQL 表。

| 来源 | 表 | 用途 |
| --- | --- | --- |
| AgentScope | `agents`、`sessions`、`messages`、`teams` | 原生运行记录、消息历史和团队协作 |
| AgentScope | `credentials` | 原生模型配置引用的凭据 |
| AgentScope | `schedules` | 原生删除 Agent 时查询并清理计划记录 |
| AgentKit | `ak_agent_definition_summary`、`ak_agent_definition_detail`、`ak_team_definition_summary`、`ak_team_definition_detail` | Agent 和 Team 的身份、状态及不可变配置版本 |
| AgentKit | `ak_agent_personal_resources` | 个人的资源选用和启停状态 |
| AgentKit | `ak_users`、`ak_groups`、`ak_virtual_users` | 真实账号、组织组、外部系统上传身份 |
| AgentKit | `ak_resource_permission`、`ak_approve` | 资源使用授权及共享申请 |
| AgentKit | `ak_skill_summary`、`ak_skill_detail`、`ak_skill_imports` | 技能身份和双版本指针、版本明细、导入任务及上架审批 |
| AgentKit | `ak_resource_assets`、`ak_mcp_credentials` | 连接器、工具目录与连接器凭据 |
| AgentKit | `ak_projects`、`ak_project_file_changes`、`ak_project_file_fingerprints`、`ak_project_reply_artifacts` | 项目、文件变更和扫描基线、回复产物 |
| AgentKit | `ak_agent_remote_runs` | 第三方专家请求去重、回包验签、结果恢复及团队回报状态 |
| AgentKit | `ak_feedback` | 回复反馈及相关会话、模型和回复快照 |
| cluster 消息总线 | `ak_bus_keys`、`ak_bus_entries`、`ak_bus_registry`、`ak_bus_leases`、`ak_bus_broadcast_payloads` | 序号与过期、队列和日志、注册状态、租约及广播载荷 |

AgentScope 原生 6 张、AgentKit 21 张，standalone 的 `init-db` 建 27 张表。企业 cluster 首次 [PG 初始化脚本](../../egis-agentkit-framework/scripts/init/pg.sql)另建 5 张消息总线表，共 32 张。PostGIS 的 `spatial_ref_sys` 属于数据库扩展。虚拟用户上传接口见 [Skill 接入指南](Skill接入指南.md)。

本地开发使用 `127.0.0.1:5433/agentscope`，默认 schema 为 `public`。应用及管理命令使用 Nacos 的 `agentkit.client.postgres.connection` 定位数据库并按 `mode` 读取固定密码或向 CyberArk CCP 取密。

## 已有 AgentKit 库升级和清理

发布前先配置 Nacos 的 `agentkit.yaml`。新库执行 `init-db`。已有独立 AgentKit 库先停止旧应用写入，从工作区根目录执行升级预览，再显式应用到目标库。

```sh
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app upgrade-db --database agentscope
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app upgrade-db --apply --database agentscope
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app cleanup-db --database agentscope
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app cleanup-db --apply --database agentscope
```

升级保留会话、资源、授权身份和总线数据。统一工作区、远程 Agent、总线表名，从 Session 记录回填项目索引和 Agent 定义关联。旧 Skill 版本从 `ak_resource_assets` 迁入技能专表，保留上传人、版本、授权和 NAS 路径。若授权版本、历史发布顺序或项目关联存在冲突，事务回滚并列出冲突项。迁移可重复执行。

清理时锁定固定名单。旧 `ak_project_sessions` 的每条关联都必须能由原生会话记录恢复。其余候选表须为空，且均需通过依赖检查。清理名单包括旧 `ak_definitions`、`ak_tool_installations`、`skills`、`mcps` 和工作台首版未开放的 `channels`、`knowledge_bases`、`knowledge_documents`、`sops`、`sop_runs`。独立 AgentScope Demo 库保留其原生功能表。

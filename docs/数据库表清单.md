# 首版 PostgreSQL 表清单

`init-db` 按工作台实际依赖建表。AgentScope 表沿用原生模型，Session 增加可索引的项目归属，AgentKit 表由框架创建，消息总线仅在 cluster 模式初始化 PostgreSQL 表。

| 来源 | 表 | 用途 |
| --- | --- | --- |
| AgentScope | `agents`、`sessions`、`messages`、`teams` | 原生运行记录、消息历史和团队协作 |
| AgentScope | `skills`、`mcps` | 个人安装和启用的资源版本 |
| AgentScope | `credentials` | 原生模型配置引用的凭据 |
| AgentScope | `schedules` | 原生删除 Agent 时查询并清理计划记录 |
| AgentKit | `ak_agent_definitions`、`ak_agent_definition_versions`、`ak_team_definitions`、`ak_team_definition_versions` | Agent 和 Team 的身份、状态及不可变配置版本 |
| AgentKit | `ak_users`、`ak_groups`、`ak_resource_grants`、`ak_share_reviews` | 身份、分组、使用授权及共享审核 |
| AgentKit | `ak_resource_assets`、`ak_skill_archives`、`ak_skill_imports`、`ak_mcp_credentials` | 资源版本、技能原始归档和导入任务、连接器凭据 |
| AgentKit | `ak_projects`、`ak_workspace_file_changes`、`ak_workspace_file_fingerprints`、`ak_reply_artifacts` | 项目、文件变更和扫描基线、回复产物 |
| AgentKit | `ak_agent_remote_runs` | 第三方专家请求去重、回包验签、结果恢复及团队回报状态 |
| cluster 消息总线 | `ak_bus_keys`、`ak_bus_entries`、`ak_bus_registry`、`ak_bus_leases`、`ak_bus_broadcast_payloads` | 序号与过期、队列和日志、注册状态、租约及广播载荷 |

全新 schema 在 standalone 模式有 25 张应用表，在 cluster 模式有 30 张。PostGIS 管理的 `spatial_ref_sys` 属于数据库扩展。生产可以使用独立的 PostgreSQL 数据库，从干净模板创建。

## 已有 AgentKit 库升级和清理

发布前先配置 Nacos 的 `agentkit.yaml`。新库执行 `init-db`。已有独立 AgentKit 库先停止旧应用写入，从工作区根目录执行升级预览，再显式应用到目标库。

```sh
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app.main upgrade-db --database egis_agentkit_versioned_dev
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app.main upgrade-db --apply --database egis_agentkit_versioned_dev
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app.main cleanup-db --database egis_agentkit_versioned_dev
demo/agentscope-demo/.venv/bin/python -m egis_agentkit_app.main cleanup-db --apply --database egis_agentkit_versioned_dev
```

升级保留会话、资源、授权身份和总线数据。统一工作区、远程 Agent、总线表名，从 Session 记录回填项目索引和 Agent 定义关联。授权升级时若同一资源存在多个互斥的旧授权版，或旧项目关联与 Session 记录不一致，整笔事务回滚并列出冲突项。迁移可重复执行。

清理时锁定固定名单。旧 `ak_project_sessions` 的每条关联都必须能由原生会话记录恢复。其余候选表须为空，且均需通过依赖检查。清理名单包括旧 `ak_definitions`、`ak_tool_installations` 和工作台首版未开放的 `channels`、`knowledge_bases`、`knowledge_documents`、`sops`、`sop_runs`。独立 AgentScope Demo 库保留其原生功能表。
